# Sharing a map

Public links work for maps created from meetup links, monitored communities, and maps assembled from communities for a chosen date. Maps start private unless you choose public visibility when creating them.

1. Open your map from **My Maps**. For a group map, **Copy public link** in **My Communities** enables public sharing and copies the URL directly.
2. Open **Map Controls** and select **Make public**.
3. Select **Copy public link** and send the link to your community.

Anyone with the link can open the map without an account. Visitors can select **View on Campfire** from meetup cards or map popups to open the meetup and check in through Campfire. Visitors can export KML, but cannot edit, delete, or trigger updates. Locations appear
as imports finish. To check the public view, open the share link in a private browser window.

## Public and owner views

| Information | Public view | Owner view |
| --- | --- | --- |
| Map name and description | Yes | Yes |
| Meetup names, groups, locations, and times | Yes | Yes |
| View on Campfire meetup links | Yes | Yes |
| Original imported source links | No | Yes |
| Last updated and scheduled update | No | Yes |
| Edit, update now, and delete controls | No | Yes |
| Saved Campfire token | No | No |

Public views also omit your account email. Review the map's description and
meetup details before sharing them.

## Make a map private again

Select **Make private**. The public
page and its exports become unavailable. Your owner view remains accessible
from **My Maps**.

Community invitations remain separate. Disabling the public link preserves access for invited, signed-in accounts.

Files someone has already downloaded remain with that person. See
[KML exports](kml-exports.md) before sharing a downloaded file.
