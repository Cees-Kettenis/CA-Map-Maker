# Exporting KML

Open a map and select **Export KML** to download its imported locations.
The file includes all locations currently fetched, even if the import is
still running. An empty map produces a file with no locations.

## Which export to use

| Export | Access | Campfire source links |
| --- | --- | --- |
| Owner map page | Map owner, signed in | Included |
| Public map page | Anyone with the public link | Omitted |

Use the public export when sharing a file without Campfire source links.
Neither export includes your Campfire token.

## Google My Maps

Create or open a map in Google My Maps and use its import option to upload the
downloaded `.kml` file. Pogo Meetups exports the file; you perform the import
manually.

A downloaded file is a snapshot. Later imports, edits, or visibility changes
in Pogo Meetups do not update that file. Export again to get the current
locations.

See [sharing](sharing-maps.md) to share a map that updates as imports finish.
